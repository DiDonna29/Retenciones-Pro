# **App Name**: Retenciones Pro

## Core Features:

- Gross Amount Input: Allow users to input their gross earnings for tax calculation.
- Automated Tax Calculation: Automatically calculate the base tax (e.g., 16%) and applicable retention based on the entered gross amount.
- Net Amount Display: Clearly display the calculated base tax, retention amount, and the final net amount.
- Theme Toggle: A button to seamlessly switch the application's visual theme between a light and a dark mode using Tailwind CSS.
- Language Switcher: A toggle button for Internationalization (i18n) to change the entire user interface language between English and Spanish.

## Style Guidelines:

- Light Theme - Primary: A vibrant, clear blue (#0EA5E9) is used for interactive elements and key indicators, evoking professionalism and reliability. This was derived from the user-provided accent color.
- Light Theme - Background: A soft, neutral light gray (#F3F4F6) provides a clean, unobtrusive canvas, keeping the focus on financial data. This was provided by the user.
- Light Theme - Accent: A calming cyan-green (#77E4D3) offers an analogous highlight, used for secondary actions or subtle distinctions without competing with the primary blue.
- Dark Theme - Primary: A bright and uplifting blue (#38BDF8) stands out against the dark backdrop, maintaining the theme of clarity for critical information and calls to action. This was derived from the user-provided accent color.
- Dark Theme - Background: A deep, rich dark blue-gray (#111827) creates a sophisticated and focused environment, reducing eye strain during prolonged use. This was provided by the user.
- Dark Theme - Accent: A lively turquoise (#40DFCB) provides a dynamic analogous contrast to the primary blue, ideal for drawing attention to secondary information or success states.
- Body and headline font: 'Inter' (sans-serif) is chosen for its modern, objective, and highly readable quality, ensuring financial data and interface text are clear and precise across all screen sizes. Tailwind CSS will be leveraged for typography utilities.
- Use a set of clear, minimalist icons related to finance, calculations, percentages, and user interface controls, ensuring quick comprehension and a professional dashboard feel. Icons should adapt to both light and dark themes.
- Employ a responsive, modular layout featuring card-like structures to clearly separate input forms, calculation results, and navigational elements, adhering to a 'clean financial dashboard' aesthetic. The layout should be adaptable to various device sizes.
- Implement subtle, swift animations for theme transitions and result updates to provide a smooth and polished user experience without being distracting, enhancing the modern feel.
